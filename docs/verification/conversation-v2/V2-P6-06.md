# V2-P6-06 — Quote-Linked Invoice and Payment Boundary

Date: 2026-10-30  
Issue: #117  
Branch: `feat/conversation-engine-v2`

## Result

Verified the Node-side Stage 6 payment contract. A payment intent can be
created only for a pending invoice linked to an active approved quote with
matching amount/currency, a hosted payment URL, and an invoice artifact hash.
The request contains no card, bank, password or payment-secret fields.

Payment state is separate from invoice state. The deterministic adapter creates
an idempotent pending intent and only an explicit local settlement changes it
to `mock_paid`; validation never interprets that as real settlement. A
payment-sandbox result requires `sandbox_paid` and provider-record evidence.
Failed, stale, mismatched or reconciliation-required callbacks cannot verify
payment.
