# V2-P3-03 — Authenticated Node trusted tool gateway

Date: 2026-10-30  
Issue: GitHub #99  
Branch: `feat/conversation-engine-v2`

## Result

**VERIFIED for the private Node read-tool boundary.** The gateway is mounted
at `/internal/v2/tools/execute` and is reachable only with the private model
gateway service key. It is not a public Chat/Admin endpoint and it does not
execute business actions.

## Security boundary

- A Node-issued HMAC scope binds tenant, application session, optional
  opportunity, published catalog version, published persona version, state
  revision, allowlist and a short expiry.
- Node re-loads the session and catalog, then checks tenant ownership, pinned
  versions, state revision and opportunity ownership before executing a tool.
- The registry contains nine explicit read-only functions:
  conversation context, persona, intent catalog, missing requirements,
  approved knowledge search, journey state, available packages, document
  requirements and action status.
- Tool arguments use strict per-function schemas. Model-supplied identity
  fields, unknown tools, cross-tenant sessions, stale revisions and mismatched
  replay arguments are denied.
- Results are bounded and sanitized. Tool outputs do not contain raw tenant,
  session or opportunity identifiers, customer document contents, secrets or
  provider credentials. Read calls are cached by scope and call ID to avoid
  duplicate execution, and redacted audit metadata is persisted.
- No CRM, n8n, payment, contract, shell, arbitrary URL or direct database
  capability is exposed.

## Compatibility correction

The signed scope is larger than the ordinary opaque references because it
contains its bounded allowlist and binding claims. The v2 contract therefore
allows `scopeRef` up to 2,048 characters while retaining strict character and
length bounds; ordinary IDs remain capped at 256 characters.
