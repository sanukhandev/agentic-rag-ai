## Result

**IMPLEMENTED and verified.** New chat sessions continue to pin the currently
published tenant persona version. Subsequent persona publication does not
rewrite that session's earlier or later responses. The public Chat API shape is
unchanged; protected audit history now records the selected persona version,
language, intent, grounding result and bounded digests for each generated
response.

## Implementation

- `chat.response` audit events record a redacted message digest, response digest,
  pinned `personaVersionId`, detected language, selected/active intent,
  grounding flag and citation count.
- Cache and durable replay events remain separate (`chat.cache_hit` and
  `chat.replay`) and do not regenerate or reword the stored answer.
- Session creation still resolves the published persona once; message handling
  reads the session's pinned version after restart or later publication.
- Persona data and response content are not added to the public response or
  audit metadata. The response digest is computed from the masked answer.
