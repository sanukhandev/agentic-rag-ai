Date: 2026-10-30
Issue: GitHub #105

## Result

**VERIFIED for the Node v2 outage-response boundary.** The fallback registry
supports eight approved families: missing knowledge, invalid model output,
rate limiting, Node tool outage, action processing, reconciliation, declined
consent and human handoff.

Each selected template is bound to the session persona version, an exact
fallback template version and the permitted language. Unapproved, unknown,
mismatched or unsafe template sets fail closed. A selected fallback is still
validated through the Node evidence guard with no citations and cannot claim
payment, contract signature, account/company creation or registration as
completed. The fallback path does not call a model, n8n or an external
provider.

## Scope and limitations

The approved template set is supplied by the trusted Node/persona
configuration boundary; the module does not silently substitute another
tenant's persona or fallback version. External provider truth remains outside
the outage path and must be established by verified callbacks or lookups.
