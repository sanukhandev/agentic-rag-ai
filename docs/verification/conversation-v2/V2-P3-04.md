## Request path

`search_knowledge` receives only a bounded query and result count. Node applies
the existing fact-preserving deterministic normalization before embedding and
full-text retrieval. The existing store query then enforces tenant, audience,
active-source and current-source-version filters. Node performs a second
source ownership/status/version check before returning evidence.

Each returned item is bounded and contains a digest citation ID, sanitized
excerpt, source version, `approval: active` and `revocation: not_revoked`.
No evidence returns `grounded: false` with an empty list. Retrieval failures
return a typed unavailable result; they do not turn model text into a factual
answer. Retrieved text remains untrusted data and cannot authorize actions.
