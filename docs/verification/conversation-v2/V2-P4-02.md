Date: 2026-10-30
Issue: GitHub #104

## Result

**VERIFIED for the Node v2 response boundary.** `guardV2Response` validates
the strict persona response, session-pinned persona/language, question policy,
pending requirement key and repeated-question state before delivery. It then
delegates evidence membership, source approval/revocation, conflicts and
claim support to the existing v2 evidence verifier.

Invalid citations, unsupported consequential claims, malformed/metadata output,
wrong persona, wrong language, repeated or irrelevant questions, and uncited
payment/invoice/contract/account completion claims are rejected. Only the
typed accepted response is deliverable. Failure returns an approved bounded
fallback plus a digest-only feedback record; raw model output is not returned
or logged by this module.

## Security and compatibility

The guard is additive and does not authorize actions or mutate business state.
Provider status remains valid only when represented by approved evidence or
verified facts. Existing tenant isolation, source filtering, response schema,
fallback and rollback boundaries remain in force.
