## Result

Verified the Node-only Stage 3 boundary. `V2OtpChallengeService` stores only
an HMAC digest, binds a challenge to tenant/session/opportunity/Lead identity,
enforces expiry and bounded retries, and makes successful verification
one-time. The account provider request requires a server-approved action,
qualified Lead, verified external Lead identity, explicit contact consent,
explicit customer confirmation, and a matching verified OTP result.

The provider contract carries an opaque local payload reference and the
verified Lead reference; it does not carry customer PII or model-selected
provider endpoints. Results require exact identity correlation and independent
provider evidence before Stage 3 completion is eligible.
