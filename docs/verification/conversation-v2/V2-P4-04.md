# V2-P4-04 — Opt-in Conversation Coordinator

Date: 2026-10-30
Issue: GitHub #106
Branch: `feat/conversation-engine-v2`

## Result

**VERIFIED for the opt-in Node coordinator path.** The existing Chat API can
delegate eligible ordinary turns to `V2ConversationCoordinator` when both the
global flag and explicit tenant allowlist select the tenant. The coordinator
issues a short-lived signed Node tool scope, sends the pinned envelope to the
private Python `/internal/v2/conversation/turn` route, validates the typed
result, runs the Node response guard, and returns only the guarded answer in
the existing model compatibility shape.

The coordinator exposes no new public endpoint and performs no business write.
Read-only tool calls remain scoped by tenant/session/opportunity/catalog/
persona/state revision. Consent, action confirmation, document, provider and
outbox paths stay in Node. A disabled flag, tenant not on the allowlist, or
v2 model/gateway failure leaves the existing route available for rollback.

## Configuration

```env
CONVERSATION_ENGINE_V2_ENABLED=false
CONVERSATION_ENGINE_V2_TENANTS=
```

Enable only with a reviewed tenant identifier and the private Python gateway
configuration. The default is disabled and no tenant is implicitly enrolled.
