# V2-P3-01 — Azure model resilience and observability

Date: 2026-10-30
Issue: GitHub #97
Branch: `feat/conversation-engine-v2`

## Result

**VERIFIED for local development and the authorized Azure deployment.** The
existing API adapter type errors were fixed without changing the public Chat
API or business gates. The model gateway now applies bounded rate limiting,
concurrency/pacing, a shared request deadline, a circuit breaker and redacted
structured events. The OpenAI SDK remains the sole transient retry owner.

## Implementation

- `services/model-gateway/gateway/reliability.py` contains the small reusable
  turn budget, sliding-window limiter and circuit-breaker primitives.
- `services/model-gateway/gateway/app.py` enforces the primitives around every
  Responses call, returns `429` with `Retry-After` for the local rate budget,
  fails closed on deadline/provider/schema errors, and logs only a request
  digest, operation, latency, status and bounded output length.
- `PlanRequest` and `NormalizeRequest` accept an optional server-supplied
  `deadlineAt`; absent deadlines use the bounded configured turn timeout.
- `services/api/src/python-model/chat-model-adapter.ts` now gives the optional
  follow-up context its actual typed default, fixing the production build while
  retaining one private request and no nested retry loop.
- `.env.example` documents the optional reliability settings. The Compose
  overlay maps the existing local endpoint key to the canonical base URL.
